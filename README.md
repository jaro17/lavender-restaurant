# Lavender Restaurant

Minimal Slim + frontend build setup for the Lavender Restaurant website.

## Safe Workflow

- Edit the frontend source in [frontend/src/pug/index.pug](/home/jardo/Codes/lavender-restaurant-2/frontend/src/pug/index.pug), not in [public/index.html](/home/jardo/Codes/lavender-restaurant-2/public/index.html).
- `public/index.html` is generated by the frontend build and can be overwritten at any time.
- The menu section is also affected by [src/Controller/Site/HomeController.php](/home/jardo/Codes/lavender-restaurant-2/src/Controller/Site/HomeController.php), which injects runtime menu HTML.
- Before larger edits, create a git commit checkpoint.

## Typical Commands

- Frontend build: `cd frontend && npm run build`
- Frontend watch: `cd frontend && npm run watch`
- PHP server: `php -S localhost:8080 -t public`

## Recommended Routine

1. Make changes in source files.
2. Run the frontend build.
3. Check the site in browser.
4. Commit the working state to git.
